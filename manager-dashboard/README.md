# Workboard — ตัวอย่าง Dashboard

เว็บไซต์ static สำหรับติดตามงานและ KPI ของ Manager รองรับจอมือถือและคอมพิวเตอร์ ไม่ต้องติดตั้งแพ็กเกจหรือ build

## เปิดตัวอย่าง

เปิด `index.html` หรือใช้ `python3 -m http.server 4173` ในโฟลเดอร์นี้ แล้วเข้า http://localhost:4173

## นำขึ้น Vercel

นำไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า Git repository แล้ว Import repository ใน Vercel เลือก Framework Preset เป็น Other และใช้ root ของโฟลเดอร์นี้เป็น Root Directory ไม่ต้องระบุ Build Command และใช้ `.` เป็น Output Directory

## ข้อมูลและการคำนวณ

Dashboard แสดงงานข้อ 1–10 และข้อย่อย 10.1–10.4 รวม 14 รายการต่อสายงาน พร้อมตารางเปรียบเทียบสถานะข้ามโครงการ เลือกข้อที่ติดตามและคลิกช่องสถานะเพื่ออัปเดตได้ ใช้พื้นที่บันทึกข้อมูลสาธิตชุดใหม่แยกจากต้นแบบเดิม


- มี 11 สายงานใน 10 โครงการ รวม OCC และ IRDN พร้อมผู้ดูแลตามที่ระบุ
- สถานะและวันส่งงานทั้งหมดเป็นข้อมูลสาธิต 154 รายการในเดือนตุลาคม 2569 ไม่ใช่สถานะจริง
- KPI ตรงเวลา = งาน Done ที่ระบุวันที่เสร็จไม่เกินกำหนด ÷ งานที่มีกำหนดส่งในรอบที่เลือก รวมงานที่ยังไม่ถึงกำหนดภายในรอบนั้น
- ตัวกรองเดือน Manager โครงการ และคำค้นมีผลกับตัวเลข กราฟ ตาราง และไฟล์ CSV ส่วนตัวกรองสถานะมีผลกับตารางและ CSV
- การอัปเดตและเพิ่มงานเก็บใน localStorage ของแต่ละเบราว์เซอร์ ไม่ใช้ฐานข้อมูลร่วมกัน
- ปุ่มเปิด Drive เปิดไฟล์หลักที่ผู้ใช้ระบุ ยังไม่มีการอ่านหรือเขียน Google Drive อัตโนมัติ

## การเชื่อมข้อมูลจริงในขั้นต่อไป

ไฟล์หลักใน Drive ปัจจุบันเป็น .xlsx ต้องเลือกวิธีอ่านไฟล์ Excel หรือแปลงเป็น native Google Sheets ก่อนใช้ Sheets API การอัปเดตจากเว็บควรผ่าน backend ที่มีการตรวจสิทธิ์ผู้ใช้และเก็บข้อมูลรับรองใน environment variables ฝั่ง server ไม่ใส่ secret ลงใน JavaScript ที่ส่งให้เบราว์เซอร์ และไม่ใช้สิทธิ์ Google Drive ของแชตเป็นสิทธิ์อัตโนมัติของเว็บ

ตัวอย่างนี้ยังไม่มีระบบเข้าสู่ระบบหรือการเชื่อมข้อมูลจริง จึงพร้อมสำหรับการสาธิต UI และนำไปพัฒนาต่อ
